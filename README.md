# albina-bot

Telegram-бот: 10 нейтральных сообщений, уточнение, прямая часть,
5 вариантов мест в Самарканде, вопрос и календарь (день и время).

## BotFather
/newbot
Name: Для Альбины
Username: AlbinaForDavid_bot (или другой свободный на _bot)
Токен сохрани для Railway.

## GitHub
Новый приватный репозиторий albina-bot, загрузить все файлы.
Токены и ID в файлы не писать.

## Railway
New Project, Deploy from GitHub repo, вкладка Variables:
BOT_TOKEN
DAVID_ID
ALBINA_ID

## Запуск
1. Альбина сама нажимает /start у бота.
2. Либо ты отправляешь боту /push.
3. Тебе приходят уведомления о этапах, ответе, дне и времени.

Команды: /start, /push (только Давид), /stop (Альбина).
